PowerShell Commands

The commands every technician should know — and the one idea (the pipeline) that makes PowerShell different.

PowerShell is an object-based shell: its commands — called cmdlets, always Verb-Noun — pass objects to each other, not text. That's why Get-Process | Sort-Object CPU -Descending just works: the pipeline hands whole process objects down the chain. Windows PowerShell 5.1 ships with Windows 10/11; PowerShell 7.x (pwsh) is the cross-platform current release — 7.6 is the LTS as of October 2026.

The pipeline — the one idea to learn

Get-Process | Sort-Object CPU -Descending | Select-Object -First 5

Read it left to right: get the process objects → sort them by CPU, biggest first → keep the first five. Second example:

Get-Service | Where-Object Status -eq Running

Get the service objects → keep only the ones whose Status equals Running. Once this clicks, PowerShell becomes obvious.

Aliases — and when not to use them

AliasReal cmdlet
ls / dirGet-ChildItem
cdSet-Location
cpCopy-Item
cat / gcGet-Content
rmRemove-Item

Aliases are fine when typing interactively. In scripts, use the full names: aliases vary by profile and edition, and Get-ChildItem reads better six months later than ls.

Three one-liners worth stealing

# Disk free space, human-readable
Get-Volume | Where-Object { $_.DriveType -eq 'Fixed' -and $_.DriveLetter } |
  Select-Object DriveLetter, FileSystemLabel, @{n='FreeGB';e={[math]::Round($_.SizeRemaining/1GB,1)}}
# Top 5 memory hogs
Get-Process | Sort-Object WorkingSet64 -Descending |
  Select-Object -First 5 Name, Id, @{n='RAM_MB';e={[math]::Round($_.WorkingSet64/1MB)}}
# Network adapters at a glance
Get-NetAdapter | Select-Object Name, Status, LinkSpeed, MacAddress

Some commands need an elevated (administrator) session — typically Restart-Service and stopping other users' processes.
