Network Cabling

The essentials: which cable for which speed, what the pinouts are, and how much power a network cable can carry.

Most network problems are physical. This is the cheat sheet: copper categories, fiber types, the two wiring schemes, and PoE wattages — everything a technician reaches for in the field.

Copper — twisted pair

Cat82,000 MHz25G/40G to ~30 mData-center, top-of-rack only

Shielding: U/UTP is unshielded. FTP usually means one overall foil; S/FTP adds a braid plus foil per pair. Shielded cable helps next to motors, variable-frequency drives and long power runs — but only if the shield is properly bonded and grounded; otherwise it can make noise worse. A normal office LAN is fine with UTP.

Single-mode = long runs, between buildings. Multimode = short runs inside a building. Connectors: LC (standard with SFP/SFP+), SC (telecom), ST (legacy), MPO/MTP (40/100/400G). Transceivers: SFP 1G, SFP+ 10G, QSFP+ 40G, QSFP28 100G. Match the optic's reach code (SR/LR/ER) to the fiber.

Coax — the survivor

RG-6 75 Ω coax still carries cable TV and ISP connections (DOCSIS), and MoCA runs Ethernet over existing home coax. The old coax Ethernet networks (10BASE2/10BASE5) are long obsolete.

The RJ45 and the two pinouts

"RJ45" is the everyday name for the 8P8C connector. The two wiring schemes, T568A and T568B, differ only in which pair goes where:

PinT568AT568B
1white/greenwhite/orange
2greenorange
3white/orangewhite/green
4blueblue
5white/bluewhite/blue
6orangegreen
7white/brownwhite/brown
8brownbrown

Straight-through = same scheme both ends (A-A or B-B) — the normal cable. Crossover = A one end, B the other — once needed between two PCs or switches, now effectively obsolete: gigabit Ethernet uses all four pairs in both directions and modern gear negotiates automatically (Auto-MDI-X).

PoE exists so APs, cameras, phones and access control need one cable instead of two. Type 3/4 ("PoE++") uses all four pairs and stays backward compatible.
